# Pilot Commander Checklist

## Start of Day

- [ ] راجع ملخص اليوم السابق (KPIs + incidents).
- [ ] أكد حالة التشغيل: normal / restricted / paused.
- [ ] راجع أي calibration changes مطبقة آخر 24 ساعة.
- [ ] أكد أن الفريق على نفس plan اليوم.

## Mid-Day Control

- [ ] مراجعة brief سريع كل 2-3 ساعات مع Ops + Clinical.
- [ ] تحقق من عدم وجود escalation غير مبرر.
- [ ] أوقف التوسع فورًا إذا ظهرت no-go triggers.

## Decisions

- [ ] أي `apply` للمعايرة يحتاج موافقة Commander.
- [ ] أي `HIGH_DRIFT` يحتاج موافقة مزدوجة قبل أي خطوة.
- [ ] إذا حدث incident: أعلن SEV وحدد owner واضح.

## End of Day

- [ ] قرار اليوم التالي: continue / restrict / pause.
- [ ] توثيق القرار وسببه في سجل pilot.
- [ ] اعتماد تقرير يومي مختصر للفريق.
