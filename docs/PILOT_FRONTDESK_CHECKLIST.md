# Pilot Frontdesk Checklist

## Start of Shift

- [ ] تأكد أن inbox والتحديثات تعمل.
- [ ] راجع المحادثات المفتوحة ذات الأولوية.
- [ ] راجع حالات الأمس غير المغلقة.

## During Shift

- [ ] عالج المحادثات حسب الترتيب:
  - [ ] emergency
  - [ ] uncertain emergency
  - [ ] unread
- [ ] عند أي سلوك غير منطقي:
  - [ ] لا تؤكد إجراء حساس مباشرة
  - [ ] ارفع الحالة للمراجعة السريعة
- [ ] استخدم feedback panel عند خطأ الفهم الطبي.

## Escalation Rules

- [ ] إذا المريض يذكر أعراض حرجة واضحة: escalated فورًا.
- [ ] إذا ظهرت رسائل متكررة بدون رد منطقي: أبلغ Ops.
- [ ] إذا فشل الحجز أو ظهر تعارض: حولها manual وابلغ الفريق.

## End of Shift

- [ ] سلّم الحالات المفتوحة مع ملاحظات مختصرة.
- [ ] سجل أي نقاط UX مربكة للمرضى.
- [ ] سجل الحالات التي تطلبت تدخل بشري كامل.
