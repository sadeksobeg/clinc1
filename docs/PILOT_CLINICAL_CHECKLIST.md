# Pilot Clinical Checklist

## Start of Day

- [ ] راجع أهم الحالات الحرجة من اليوم السابق.
- [ ] تأكد أن clinical overrides تعمل كما هو متوقع.
- [ ] راجع أي calibration apply حديث وتأثيره المتوقع.

## During Day

- [ ] راجع عينات من emergency decisions كل ساعة.
- [ ] صحح الحالات غير الدقيقة عبر feedback panel.
- [ ] اضمن جودة feedback:
  - [ ] note واضح
  - [ ] reviewer موثوق
  - [ ] الحالة مرتبطة بتنفيذ فعلي

## Clinical Safety Gates

- [ ] أي حالة `loss_of_consciousness` تعامل كطارئة بلا تأخير.
- [ ] حالات `breathing_issue` تبقى high-priority.
- [ ] عند misclassification pattern: أبلغ Ops + Commander فورًا.

## End of Day

- [ ] تقرير false positives / false negatives.
- [ ] تحديد 3 أسباب متكررة للالتباس الدلالي.
- [ ] توصية سريرية: tighten / keep / relax (مع مبرر).
